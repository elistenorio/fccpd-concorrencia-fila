      Demonstração de OOM

      O serviço estresse-memoria tem mem_limit: 128m e aloca 4 MB por segundo. Ele aparece na tabela, passa do limite de alerta, recebe o evento oom do Docker e para com código 137 (SIGKILL). No nível 1, o oom_kill do kernel sobe.

      docker compose --profile demo up estresse-memoria      # roda até o OOM (~30 s)
docker compose --profile demo rm -f estresse-memoria   # limpa o container morto

      Saúde dos serviços

      Uma sonda por serviço a cada 1 s, falando o protocolo de cada um: GET / na api e em recomendacoes, PING do RESP no Redis e SSLRequest no Postgres. Nas últimas 60 medidas: latência média, p95 (quick_sort da janela), jitter (média de |Δ| entre medidas seguidas) e perda.

      Linha do tempo de eventos

      Eventos dos 3 níveis numa ArvoreBusca por (timestamp, seq); intervalo() devolve a janela escolhida. Alertas em vermelho.
